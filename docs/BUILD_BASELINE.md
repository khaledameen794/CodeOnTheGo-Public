# خط الأساس المتحقق للبناء

## النطاق

هذا السجل يثبت أن الفرع `stage` من النسخة الخاصة يبني APK تصحيحياً لمعمارية
`arm64-v8a` عبر مهمة Gradle الصحيحة. لا تستخدم هذه الوثيقة كبديل عن اختبارات
الميزات؛ بل كشرط دخول قبل إجراء تغييرات معمارية في الوكيل أو الواجهة.

## المهمة الصحيحة

يعرف المشروع نكهات ABI، ولذلك لا توجد مهمة عامة باسم `:app:assembleDebug`.
المهمة المستهدفة لهاتف Android حديث بمعمارية `arm64-v8a` هي:

```bash
./gradlew :app:assembleV8Debug
```

تسبقها عند تشخيص Kotlin/KAPT المهمة الأصغر التالية:

```bash
./gradlew :app:compileV8DebugKotlin
```

يجب أن تبقى إعدادات بيئة الجهاز، مثل `sdk.dir` ومسار `aapt2` المحلي، خارج Git.
ولا يجوز تعديل `gradle.properties` المتعقب لاستيعاب خصائص Sandbox أو Termux
المحلية.

## ضوابط CI المتعمدة

يُنشأ مفتاح تصحيح مؤقت داخل مسار التوقيع الذي يتوقعه المشروع، ولا تُستخدم
مفاتيح إنتاج أو بيانات Firebase حقيقية. كما أن تعطيل المعالجة التدريجية لـ
KAPT مقتصر على أمر التحقق في CI لتجاوز خلل Room/KAPT في بيئة المستضيف؛ لا
يتحول إلى إعداد دائم متعقب للمستخدم أو Termux.

## معيار الاستمرار

يجوز البدء في نواة وكيل Termux فقط بعد توفر هذا الدليل. وكل تغيير لاحق يمس
مسار الإنشاء أو صلاحيات الأدوات أو ربط Termux يجب أن يضيف اختباراً وحدوياً
مناسباً، ثم يعيد تشغيل تحقق V8Debug قبل دمجه.
